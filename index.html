FOUNDATION

What is Git?

Definition

Git is a distributed version control system used to track changes in source code and help developers collaborate on software projects.

📦

Version Control

Track changes made to your project and restore previous versions when required.

👥

Collaboration

Multiple developers can work on the same project using branches and merges.

🌿

Branching

Create separate development environments for features, fixes and experiments.

COMMAND LINE

Essential Git Commands

git init

Creates a new Git repository.

git init

git status

Shows the current repository status.

git status

git add

Adds changes to the staging area.

git add .

git commit

Saves staged changes in Git history.

git commit -m "message"

git log

Displays the commit history.

git log --oneline

git diff

Shows changes that are not staged.

git diff

git branch

Lists or manages Git branches.

git branch

git switch

Switches between branches.

git switch main

git merge

Combines changes from another branch.

git merge feature

Create a feature branch

git switch -c feature/login

git commit -m "Add login feature"

git push -u origin feature/login
